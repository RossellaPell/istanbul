ISTANBUL TRAVEL APP - VERCEL READY

Contenuto:
- index.html: web app completa
- vercel.json: configurazione Vercel per sito statico

Deploy consigliato:
1. Estrai lo ZIP.
2. Importa la cartella in un repository GitHub e collegalo a Vercel, oppure usa Vercel CLI dalla cartella.
3. Framework Preset: Other
4. Build Command: lascia vuoto
5. Output Directory: lascia vuoto

La web app usa Leaflet/OpenStreetMap e alcune risorse esterne, quindi richiede una connessione internet per mappe e font/immagini remote.
